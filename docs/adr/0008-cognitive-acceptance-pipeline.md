# LLM proposals require cognitive acceptance

LLM создаёт только `CortexProposal`: semantic appraisal, возможные goal, intention, plan, memory interpretation и communication. `CognitiveGate` независимо возвращает durable `CognitiveDisposition`; только `Accepted` может породить отдельную canonical transition принятия goal/intention, а физическое исполнение затем проходит motor/physical validation. Это отделяет языковое предложение от воли, neural state и объективного результата.
