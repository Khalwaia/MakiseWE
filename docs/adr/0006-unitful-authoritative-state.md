# Unitful authoritative state

Authoritative state хранит физические величины с единицами, счётчики или определённые безразмерные величины: probability, fraction, receptor occupancy и strain. Произвольные normalized scores запрещены, потому что они скрывают размерность, не поддерживают conservation и не дают проверяемого пути повышения разрешения; UI может показывать удобную шкалу только как явно неавторитетную projection исходных величин.
