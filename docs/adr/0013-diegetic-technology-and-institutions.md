# Technology and institutions remain inside the causal world

Devices, application execution and networks extend the causal map with digital/computation domain L8; organizations, contracts, services and socially recognized claims add institutional/economic domain L9. They remain parts of the simulated world rather than privileged orchestration shortcuts. Code executes in a deterministic sandbox and reaches sensors, devices or external systems only through scoped `CapabilityGrant`s. Organizations have roles and obligations but no independent consciousness; designs, contracts and orders express claims or intentions rather than physical results. Real external effects additionally require host authorization and an idempotent receipt so replay never repeats them.
